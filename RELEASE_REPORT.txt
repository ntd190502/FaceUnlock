BLE framing v1
--------------
Magic: "FU"
Version: 1
Kinds: request=1, response=2
Header: 9 bytes
Windows request frame size: 20 bytes total
Maximum reassembled message: 16 KiB
Incomplete assembly timeout: 15 seconds
Duplicate chunks: ignored
Out-of-order chunks: supported
Legacy unframed packet: accepted for backward compatibility

Environment limitations
-----------------------
- The current Linux container does not have the .NET SDK, Windows Runtime APIs, Visual Studio, or Windows SDK, so the Windows projects cannot be compiled locally here.
- The current Linux container is not Xcode/macOS, so the full iOS app cannot be linked against CoreBluetooth/LocalAuthentication locally.
- Those platform builds are delegated to the repository GitHub Actions workflows included/updated by this overlay.
- GitHub connector read access works, but repository write operations returned HTTP 403 "Resource not accessible by integration". Therefore this overlay was NOT pushed to GitHub automatically.

Important product limitation
----------------------------
This phase completes FaceUnlock approval, transport, pairing, device targeting, and hardening work. `windows/CredentialProvider/` remains a scaffold. A successful phone approval is not, by itself, a Windows/LSA passwordless unlock implementation.

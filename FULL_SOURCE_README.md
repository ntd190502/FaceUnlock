# FaceUnlock FULL COMPLETE SOURCE

This archive is a full source tree, not an overlay.

## Configure before running

1. Copy `hosting/config.example.php` to `hosting/config.php`.
2. Fill MySQL DSN/user/password.
3. Fill Telegram `bot_token` and `chat_id`.
4. Keep `base_url` equal to the deployed HTTPS URL.
5. Import `hosting/schema.sql`.
6. Point the web document root to `hosting/public/`.

Windows/iPhone ECDSA keys and bearer tokens are generated by the pairing flow; do not hard-code them.

## Important limitation

This source completes Face ID approval, Telegram/foreground online flow and BLE/QR transport.
`windows/CredentialProvider/` is still a scaffold and does not turn a successful phone approval into an actual Winlogon/LSA unlock.
